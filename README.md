# PostureCare: Smart Posture Correction Belt

Wearable belt that measures torso tilt with an MPU6050 and alerts with a vibration motor, then a buzzer, when posture drifts from a calibrated baseline. Controller: ESP32.

## Structure

* `firmware/` : Arduino sketch and flashing steps
* `electronics/` : wiring/pin map, bill of materials (add KiCad `.kicad\\\_sch` / `.kicad\\\_pcb` here)
* `cad/` : enclosure and mount (add native CAD files here)
* `evidence/` : lab photos, screenshots, DRC log, test captures
* `docs/` : setup guide
